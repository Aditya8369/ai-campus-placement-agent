Developer Guide: Adding & Consuming Feature Flags

Feature flags allow developers to deploy code safely, run dark launches, and execute percentage rollouts without service restarts.

In Python Routes / Handlers:
from utils.feature_flags import is_feature_enabled

@app.route("/advanced-analysis")
def advanced_analysis():
    # Automatically checks DB override, env vars, and user rollout bucket
    if not is_feature_enabled("batch_comparison_v2", user=session.get("user_id")):
        return render_template("fallback_view.html")
    return render_template("v2_view.html")
