Understanding Service States

Operational
The service is healthy and operating within normal response thresholds. All features are fully functional.
Degraded
The application remains active. If the Gemini API key is missing or unconfigured, the system automatically uses deterministic scoring and Safe Demo Mode.
Unavailable
A critical outage occurred (e.g. database lock or storage failure). If you encounter this, retry in a moment or notify the campus administrator.
